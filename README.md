## 📖 Présentation

Les notes d'un devoir peuvent être sur 90, 150, 80, 75... alors qu'on est habitué aux notes sur 20. Cette application web permet de convertir rapidement une note pour mieux se situer et comparer ses résultats.

## ✨ Fonctionnalités

- 🔄 Conversion d'une fraction vers une autre base (exemple : 8/75 vers /20, /100, /10 ou GPA)
- 🎯 Résultat instantané
- 📱 Interface simple et intuitive

## 💡 Pourquoi ce projet ?

Créé pendant mes études en classes préparatoires, où les notes des devoirs surveillés sont sur des barèmes très variés. L'objectif : un outil simple pour se repérer rapidement.
